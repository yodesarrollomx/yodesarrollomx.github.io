# Portada de los tableros · Yo Desarrollo

Este repo existe por una razón concreta: es el **sitio de organización**, y GitHub
aplica su dominio personalizado a **todos los demás repos de la organización**.
Poniendo `tableros.yodesarrollo.mx` aquí, los 15 tableros quedan servidos en
`tableros.yodesarrollo.mx/<tablero>/` sin tocar uno por uno.

> "If you set a custom domain for a user site or organization site, that same
> custom domain will be used for all project sites owned by the same account."
> — documentación de GitHub Pages

## No borrar

Si se borra este repo o se le quita el dominio, **los 15 tableros se mudan de
dirección de golpe** y las ligas que andan por WhatsApp y los QR impresos dejan
de llevar a ningún lado.
